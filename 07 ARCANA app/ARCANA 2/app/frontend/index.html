Step 01 — Data Input

Upload your expression data

Accepts raw count matrices, normalized expression tables, or pre-processed TPM/FPKM files. ARCANA handles the biotype filtering automatically.

📊

Count Matrix

Raw or normalized count matrix. Genes as rows, samples as columns. Supports .csv, .tsv, .txt

🧬
Click or drag count matrix here
🏷️

Sample Metadata

Sample condition, tissue/organ of origin, patient ID, disease status. Minimum: SampleID + Condition columns — must match your config/project.yaml settings.

🗂️
Click or drag metadata here
📌

GTF Annotation

GENCODE or Ensembl GTF for biotype classification. lncRNAs, pseudogenes, and protein-coding genes will be separated automatically.

Step 02 — Analysis Modules

Select your analyses

Choose one or more modules. Each runs as a separate pipeline stage with its own R/Python script pulled from the ARCANA GitHub repository.

✓

lncRNA Identification

Filter by biotype, annotate against GENCODE, classify subtypes (lincRNA, antisense, processed pseudogene)

✓

WGCNA Network

Auto soft-threshold selection, signed hybrid network, module eigengene computation, hub gene identification

✓

Differential Expression

DESeq2 with apeglm shrinkage. All comparisons from your project config run automatically.

Hub Gene ML

XGBoost + SHAP feature importance ranking of hub lncRNAs by trait association.

Cross-organ Comparison

Preserved modules across tissues (WGCNA modulePreservation), Jaccard overlap, shared hub lncRNAs

Functional Enrichment

GO, KEGG, and Reactome enrichment for module gene sets. lncRNA–TF regulatory network via ENCODE

⚙️

WGCNA Parameters

Leave on Auto for optimal soft-threshold selection
