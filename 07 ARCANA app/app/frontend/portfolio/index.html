ARCANA — lncRNA Network
Analysis Platform

A fully standalone research software system for pancreatic islet co-expression analysis, built from the ground up as part of my MSc dissertation on Type 2 Diabetes.

  • Designed and implemented a multi-step RNA-seq pipeline: raw count QC → DESeq2 differential expression (apeglm shrinkage) → WGCNA co-expression network → hub gene prioritisation
  • Applied XGBoost with 5-fold cross-validation and SHAP explainability to rank hub lncRNA candidates by disease relevance, combining network topology with DE statistics
  • Built a FastAPI backend with WebSocket live progress streaming, SQLite run-history database, and full-text document search — making the full pipeline operable via a web interface
  • Automated publication-ready output: 19 high-resolution figures (300 dpi PNG/PDF/SVG), methods text, figure legends, and per-gene supplementary cards
  • Identified 5 disease-associated modules (brown, yellow, green, red, black) and characterised their clinical trait correlations with T2D status, HbA1c, and BMI
